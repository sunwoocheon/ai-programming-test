## ① 무엇을 하나요 (What)

성적 CSV 파일을 읽어 0~100 사이의 올바른 점수는 목록으로 저장하고, 잘못된 데이터는 줄 번호와 이유를 기록하는 프로그램입니다.



## ② 왜 만들었나요 (Why)          ★ AI는 이 칸을 못 씁니다

10주차에 만든 성적 CSV 읽기 함수가 여러 상황에서도 제대로 작동하는지 확인할 필요가 있었습니다. 실제 CSV에는 빈칸이나 범위를 벗어난 점수처럼 잘못된 값이 들어갈 수 있으므로, 정상적인 경우뿐 아니라 예외 상황까지 테스트해 보고자 했습니다.



## ③ 어떻게 쓰나요 (How)

 아래 명령어를 터미널에 입력합니다. 명령어는 ai-programming-week11 폴더에서 실행합니다.

```bash
# 설치
python -m pip install pytest
# 실행
python week11/load_scores.py week11/scores.csv
```
CSV 파일의 첫 줄은 `name,score` 형태로 작성합니다. 예를 들어 `철수,90`은 정상 데이터로 처리하고, `영희,105`는 점수 범위를 벗어났다는 이유로 제외합니다. 실행하면 읽은 데이터와 건너뛴 줄의 개수 및 이유가 출력됩니다.

## ④ 어떻게 테스트하나요

같은 `load_scores.py` 함수를 대상으로 A와 B 두 가지 테스트 파일을 실행했습니다. A는 기본적인 정상·예외·경계값을 확인하고, B는 중복 이름·헤더 오류·파일 접근 권한 등 더 다양한 상황을 확인합니다.

```bash
# A 테스트
python -m pytest week11/test_ai_A.py -v

# B 테스트
python -m pytest week11/test_ai_B.py -v
```
실제로 실행하여 확인한 결과는 다음과 같습니다. 실행 시간은 컴퓨터 환경에 따라 달라질 수 있습니다.
```
A 테스트
11 passed in 0.12s

B 테스트
6 failed, 15 passed in 0.37s
```
A 테스트는 11개 모두 통과했습니다. B 테스트는 총 21개 중 15개가 통과하고 6개가 실패했습니다. 실패한 항목은 중복 이름 처리 2개와 잘못된 해더 처리 4개입니다.
